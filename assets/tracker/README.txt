Data Collection Agent - InteractionLab (ES Module)
===================================================

This package contains ES module scripts. Import the functions you need
directly into your JavaScript/TypeScript components:

  import { initTracking, finishTracking } from './tracker-events.js';
  import { getCurrentSceneId } from './tracker-helpers.js';
  import { registerElement, addFocusAndBlurEvents } from './tracker-elements.js';
  import { postNumberDD, postStringDD, postDateDD } from './tracker-visualization.js';
